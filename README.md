Most of my professional work lives elsewhere. This GitHub is where the side projects, experiments, and occasional useful tool end up.

## Projects

### [gamedacctl](https://github.com/AndreasDellrud/gamedacctl)

Native Linux control for the original SteelSeries GameDAC and wired Arctis Pro, written in Rust.

Built because I still like my decade-old headset and apparently that was enough reason to learn how its USB HID protocol works.

### [omarchy-gamedacctl](https://github.com/AndreasDellrud/omarchy-gamedacctl)

An Omarchy/Quickshell panel for `gamedacctl`, providing GameDAC status, lighting profiles, and controls directly from the desktop.

### [yaak-eldritch](https://github.com/AndreasDellrud/yaak-eldritch)

An implementation of the Eldritch theme for the Yaak API client.
